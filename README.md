# ⚡ BlockNova Hackathon 2026

Official website for **BlockNova Hackathon 2026**, organized by the **Algorand Blockchain Club** at **Vardhaman College of Engineering**, Hyderabad, and sponsored by the **Algorand Foundation**.

📅 **Event Dates**: September 18–19, 2026 (48-Hour Non-Stop Hackathon)  
📍 **Venue**: Vardhaman College of Engineering, Kacharam, Shamshabad, Hyderabad  
🏆 **Prize Pool**: ₹10,000+ in Cash & Grants  

---

## 🌟 Key Features

- **Live Countdown Timer**: Real-time ticker counting down to September 18, 2026, 09:00 AM IST.
- **Problem Statements Explorer (#PS)**: Categorized problem catalog (`Blockchain`, `AI`, `Cybersecurity`, `FinTech`, `Web3`, `Open Innovation`) with deep-dive modal.
- **7-Phase Event Scheme & Evaluation**: Operational roadmap and weighted evaluation metrics visualizer.
- **Day 1 & Day 2 Schedule**: Interactive hour-by-hour timeline for all 48 hours.
- **Multi-Step Team Registration Wizard**:
  - Step 1: College Details
  - Step 2: Team Name & 2–4 Member Size Selector
  - Step 3: Team Leader Information
  - Step 4: Dynamic Team Members
  - Step 5: Review & Confirmation Checkbox
  - Step 6: Success Screen with Unique Registration ID (`BNH26-XXXX`) and PDF Registration Pass generation.
- **Venue & Travel Guide**: Embedded Google Maps view, transit details from RGIA airport/bus, and campus guidelines.
- **Interactive FAQ Accordion**: Categorized frequently asked questions.
- **Organizer Admin Dashboard**:
  - Secure passcode login (`blocknova2026` or `admin123`)
  - Summary metrics (Total Registrations, Approved, Pending, Rejected, Colleges)
  - Search & filterable registration table with 1-click Approve/Reject
  - CSV spreadsheet export

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons, Glassmorphism Cyber Theme
- **Utilities**: jsPDF (Registration Pass generation), Canvas Confetti

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/<YOUR_USERNAME>/<YOUR_REPO_NAME>.git
cd <YOUR_REPO_NAME>
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
